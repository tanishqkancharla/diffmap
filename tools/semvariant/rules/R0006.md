# Load the Maui skill before changing application UI.

Load the [Maui skill](../../../.agents/skills/maui/SKILL.md) before building or changing application UI. It owns component selection, tokens, styles, and supported customization. This trigger does not apply to server-only or parser work in the same directories, and does not require migrating unrelated existing UI.
