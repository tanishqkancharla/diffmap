# Generate guidance indexes from one canonical rule source.

Author rules as `RNNNN.md` in `tools/semvariant/rules/`. Each has frontmatter containing only a nonempty, duplicate-free `guides` list of existing repository directories, followed by exactly one nonempty H1 title and a Markdown body. Use `.` for repository-wide guidance. IDs are stable identities, not priorities; use the next unused ID for a new claim.

`npm run semvariant -- generate` projects titles into each scope's `AGENTS.md`. It repairs missing or changed generated guides and deletes stale generator-owned guides. It refuses to overwrite authored guides; migrate their guidance deliberately before replacing them. Do not hand-edit generated guides or retain a parallel handbook.

After editing, merging, retiring, or re-scoping rules, generate the indexes, then run `npm run semvariant:check`. Retrieval commands also reject stale projections. The check validates rule structure and projections, not semantic compliance.
