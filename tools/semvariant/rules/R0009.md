# Search and consolidate rules before adding a claim.

Search existing titles and bodies with `npm run semvariant -- search <terms>` and read nearby claims before adding a rule. Edit the existing owner when guidance changes. Merge overlapping claims, retain a stable surviving ID, delete retired sources, and regenerate guides. Keep distinct claims separate even when they affect the same files.

Record settled, user-authorized guidance rather than speculative preferences or a workaround for one task. Scope it to directories where it matters and remove guidance that no longer applies.
