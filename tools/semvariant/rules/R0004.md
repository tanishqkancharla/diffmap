# Use the Productdoc skill for repository specs and walkthroughs.

Use the [generate-product-doc skill](../../../.agents/skills/generate-product-doc/SKILL.md) when creating or updating repository specs and walkthroughs. Keep them in `.diffmap/`, tracked with the work. The skill and CLI guide own document format, validation, serving, and review; do not maintain a second authoring guide in these rules.
