# Read applicable full rules before editing or reviewing.

Rule files in `tools/semvariant/rules/` are the source of truth for repository guidance. Their `guides` lists assign titles to directory-scoped `AGENTS.md` files. A rule applies in each listed directory and its descendants, together with ancestor rules. Titles are index entries, not substitutes for the full rationale and exceptions.

Use the [retrieving-semvariant skill](../../../.agents/skills/retrieving-semvariant/SKILL.md) to retrieve applicable rules or maintain guidance. Read the relevant full rules before editing or judging a violation. Apply guidance to the changed area without turning a focused task into a repository migration.

Semvariant checks rule structure and generated-index drift, not whether code obeys the prose. Reviewers judge compliance from full bodies and cite the rule ID, canonical rule path, and violating code. Do not invent rules from titles or flag an unrelated pre-existing mismatch as introduced by the change.
